LoanPilot is an AI-powered, agentic loan underwriting platform designed to automate loan application evaluation using LLMs, retrieval-augmented generation (RAG), and business rule engines. Built with NestJS, TypeScript, PostgreSQL/pgvector, Redis, BullMQ, and Next.js, it integrates credit checks, EMI/FOIR calculations, and policy retrieval to generate evidence-backed lending decision reports. Implemented a 12-rule validation engine to enforce lending policies, prevent unsafe approvals, and escalate borderline applications for human review. Evaluated across 80 synthetic test cases, the system achieved 91% decision accuracy with zero unsafe approvals, demonstrating reliable AI-assisted decision-making for fintech workflows.
